# 작은 세계 우체국 확장 원고

## 상태

`little-post-office@3`는 수직 시제품을 첫 작품 분량으로 확장한 개발용 원고 초안의
연속성 보완 버전이다. 원본은 `content/stories/little-post-office/episode-01-v3.json`,
불변 SHA-256 앞 12자리는 `87c99af44e84`다. 플레이테스트와 퇴고 전에는 프로덕션에
노출하지 않는다.

v2 원본과 hash `a7892245b183`은 저장 호환성을 위해 그대로 보관한다. 앱 작품 목록은 같은
`storyId`의 최신 버전인 v3만 보여 주며, 이미 시작한 v1·v2 기록은 해당 원고와 hash로 복원한다.

## 범위

| 항목 | 값 |
| --- | ---: |
| 전체 노드 | 18 |
| 읽기 장면 | 16 |
| 선택 | 25 |
| 엔딩 | 2 |

| 도달 상태 | 47 |

| 엔딩까지 최소 선택 | 11회 |
| 경로 기반 예상 읽기 시간 | 약 15~17분 |

수직 시제품의 빈집·내일 날짜 소인·마지막 우편함을 유지하면서 다음 내용을 포함한다.

- 파도 사이 책방에서 연우의 배달 장부와 개인 일기 중 하나를 선택한다.
- 지도 경로에서는 배달하지 못한 일곱 주소와 소라의 편지를 확인한다.
- 일기 경로에서는 연우가 타인의 편지를 대신 판단했던 사실을 확인한다.
- 등대지기 해진의 답장을 기다릴지 바로 출발할지 선택한다.
- 소라와 동행하거나 혼자 간 선택이 마지막 열쇠 장면까지 이어진다.
- 장부를 우체국에 돌려보내거나 마지막 편지를 간직해 두 엔딩을 수집한다.

## v3 정적 연속성 수정

v2 정적 검토에서 찾은 명확한 연결 오류만 v3에서 고쳤다. 분량과 감정선은 플레이테스트 전
임의로 확장하지 않았다.

1. 단독 책방 경로에서 놋쇠 열쇠를 발견한 뒤 문을 여는 행동을 추가했다.
2. 바닷길의 두 발자국이 현재 동행 인원을 뜻하는 것처럼 읽히지 않도록 표현을 다듬었다.
3. `letters-returned` 공통 엔딩에서 단독 경로에도 소라가 함께 있었다고 단정한 문장을 제거했다.
4. `last-letter-kept` 공통 엔딩에서 단독 경로에도 세 사람이 돌아간다고 단정한 문장을 제거했다.

회귀 테스트는 두 공통 엔딩에 이전의 경로 한정 문구가 다시 들어오지 않는지 확인한다. 원고
검토에서는 `동행/단독 × 주소/고백 × 두 엔딩`의 실제 표시 문구를 모두 읽어 소라의 위치와
장면 인원이 앞선 선택과 맞는지 확인한다.

## 분기·저장 계약

동행 여부와 책방에서 고른 기록은 서로 독립적이므로 `동행/단독 × 주소/고백` 네 조합이
모두 엔딩에 도달해야 한다. 엔진 테스트가 네 조합을 고정하며 조건에 맞지 않는 등대 선택은
노출하지 않는다. 두 엔딩의 최소 경로는 각각 11회 선택이다.

파일 SQLite 테스트는 v2를 `lighthouse-room`에서 닫고 다시 열어 같은 버전·장면·flag를
복원한 뒤 `letters-returned` 엔딩까지 저장한다. v3가 목록의 최신 원고가 된 뒤에도 v1·v2
저장을 최신 버전으로 자동 변경하지 않는 것을 카탈로그와 저장소 테스트로 확인한다.

## 플레이테스트에서 확인할 항목

1. 실제 완주 시간이 목표 20~30분에 가까운지 기록한다.
2. 지도책과 개인 일기의 차이가 선택 전에 충분히 예상되는지 묻는다.
3. 소라 동행 여부가 후반 장면에 반영됐다고 느끼는지 확인한다.
4. 두 마지막 선택이 정답 찾기가 아니라 감정적으로 다른 결말로 읽히는지 확인한다.
5. 긴 본문을 큰 글자와 작은 화면에서 읽을 때 피로한 구간을 표시한다.
6. 네 가지 핵심 경로에서 인물의 위치와 장면 전환이 자연스러운지 확인한다.

추가 문장 수정도 기존 v3 파일을 덮어쓰지 않고 다음 콘텐츠 버전으로 등록한다. 현재 앱의
경로 기반 예상치는 15~17분이므로 실제 플레이도 짧다면 장면의 의미를 해치지 않는 중간 사건을
다음 버전에 추가하거나 제품 목표 시간을 조정한다. 분량만 맞추기 위한 문장 증가는 하지 않는다.

## v4 작업 원고의 서사 검수 — 2026-10-01

v4 CSV를 수정했다. 아직 검수·출시 승격 전이며 런타임 v3와 기존 진행 기록은 변경하지 않는다.

- 열 통의 편지 수와 매년 목요일 소인의 주기를 맞추고, 편지가 안내하는 시간을 오늘 밤으로 통일했다.
- 접힌 편지에서 열쇠를 얻는 행동, 소라의 빈 고리, 동행 경로에서 열쇠를 건네는 행동을 연결했다.
- 책방에서는 한 책만 가져가고 등대에서는 선택한 기록만 펼친다. 공통 장면이 지도와 일기를 모두 소유했다고 전제하지 않는다.
- 소라의 봉투를 얻지 않은 일기 경로에도 맞도록 동행 장면에서 오래된 배달표를 돌려주는 행동으로 전환했다.
- 해진의 두려움은 잡으려던 손을 거두는 행동과 고백으로 드러낸다. 등장하지 않은 사진과 나이를 비교하는 문구를 제거했다.
- 장부를 돌려주는 결말에서는 소라에게 인계하고 쉬어 가는 행동을, 편지를 간직하는 결말에서는 장부를 우편함에 남기고 돌아오는 행동을 썼다. 두 선택의 책임과 경계를 함께 남긴다.

회귀 검사에서 `첫 응답 2 × 동행 3 × 기록 2 × 해진 답장 2 × 엔딩 2`의 48개 경로를 실제 엔진으로
완주하고 동행 flag와 목적 엔딩을 대조한다. 이는 분기와 명확한 서술 연결의 정적 검수이며,
감정의 설득력·독서 피로·선택 만족도는 앞선 플레이테스트 항목으로 별도 확인해야 한다.
