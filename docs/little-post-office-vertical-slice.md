# 작은 세계 우체국 수직 시제품

## 상태와 목적

`little-post-office@1`은 첫 작품의 분위기와 핵심 루프를 확인하는 약 5분 분량의 개발용 원고다.
제목은 **작은 세계 우체국: 내일의 소인**이며 프로덕션 콘텐츠로 공개하지 않는다.
원본은 `content/stories/little-post-office/episode-01.json`, 불변 SHA-256 앞 12자리는
`e427b6639505`다. 수정이 필요하면 v1과 저장 호환을 유지하고 version 2 파일을 추가한다.

## 범위

| 항목 | 값 |
| --- | ---: |
| 전체 노드 | 9 |
| 편지 노드 | 7 |
| 선택 | 13 |
| 엔딩 | 2 |
| boolean flag | 2 |
| 도달 상태 | 17 |
| 표시 문자열 | 1,839자 |
| 엔딩까지 최소 선택 | 5회 |

빈집으로 십 년 동안 배달된 편지, 내일 날짜의 등대 우체국 소인, 사라진 전 주인 연우를
소개한다. 플레이어는 경고를 소라와 공유할지, 등대에 함께 갈지, 마지막 장부를 우체국에
돌려놓을지를 선택한다.

## 분기 계약

- 첫 봉투를 바로 받거나 발신인을 물을 수 있다. 질문하면 소라의 추가 답변 장면을 거친다.
- 경고를 공유하면 `sora-remembers`, 숨기면 `second-warning` 장면으로 나뉜다.
- `with-sora=true`에서는 `enter-together`, false에서는 `enter-alone`만 노출된다.
- 장부를 돌려놓으면 `letters-returned`, 마지막 편지를 간직하면 `last-letter-kept`를 해금한다.
- 어느 경로에서도 막힌 상태가 없고 두 엔딩은 조건 탐색으로 도달 가능해야 한다.

## 검증

- 콘텐츠 Schema, ID·조건·효과, DAG, 도달 상태와 불변 hash 검사 통과.
- 공유/동행 경로와 비공개/단독 경로, 숨긴 뒤 소라를 다시 부르는 경로를 엔진 테스트로 고정.
- 파일 DB를 닫고 `lighthouse-road`에서 복원한 뒤 `letters-returned` 엔딩 저장 확인.
- iOS·Android UI 계약에서 작품 카드 선택부터 다섯 선택과 엔딩 보관까지 통과.
- 두 작품 카탈로그 상태에서 iOS·Android 네이티브 SQLite 스모크 각각 8개 통과.

## 정식 원고로 확장할 때

현재 시제품은 연우와 소라의 핵심 미스터리만 다룬다. 목표 20~30분 원고에서는 책방 주인
연우의 과거 기록, 등대지기 해진, 배달하지 못한 여러 주소를 중간 에피소드로 확장한다.
플레이테스트에서 선택의 의미와 읽기 속도를 확인하기 전에는 아트·음향·과금 범위를 늘리지 않는다.

후속 확장본은 [작은 세계 우체국 확장 원고](little-post-office-expanded-draft.md)에서 관리한다.
