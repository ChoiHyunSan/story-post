# 제품 기획

## 방향

짧은 선택형 스토리를 모은 모바일 게임. 각 작품은 세계관과 표현 방식이 다르지만
진행·저장·다시 시작·엔딩 수집은 공유한다. 대상은 짧은 시간에 읽고 선택하는 경험을 원하는 사용자라는 가설이다.
초기 성공 기준은 첫 작품의 완주 의향, 선택의 영향 이해, 다른 결말을 보고 싶은지다.
초기 평가는 소수 플레이테스트와 인터뷰로 하고 분석 SDK는 먼저 넣지 않는다.

## 첫 작품: 작은 세계 우체국

포근한 섬마을 미스터리. 빈집에 이사 온 주인공에게 십 년 동안 도착한 편지가 전달된다.
편지의 발신인과 이전 거주자의 사연을 알아가는 이야기다.

- 등장인물: 우체부 소라, 사라진 우체부 연우, 등대지기 해진. 이름은 가안.
- 장소: 주인공의 집, 우체국, 닫힌 책방, 바닷길과 등대. 연우의 기록을 따라 이동한다.
- 목표 분량: 20~30분, 편지 10통 안팎, 결말 2개. 플레이테스트로 조정.
- 현재 v3 경로 기반 예상은 15~17분이다. 실제 완주 시간 확인 후 다음 원고 버전의 분량 또는 목표를 조정한다.
- 구조: 주요 사건은 합류하고, 선택은 신뢰·발견 단서·후속 문구·결말에 영향을 준다.
- 핵심 갈등: 이전 주인의 편지를 누구와 공유하고, 마지막 편지를 어디로 전달할 것인가.
- 5분 수직 시제품: 7개 편지 노드에서 공유·동행·마지막 장부 선택이 두 결말로 이어지고 진행을 저장한다.
- 실시간 대기 없이 원하는 속도로 진행한다. 실시간 AI 대화는 포함하지 않는다.

## 화면과 초기 범위

작품 목록(처음엔 실제 작품 1개), 작품 소개, 편지/선택 화면, 받은 편지 기록, 결말, 설정.
설정은 글자 크기·화면 움직임 줄이기·진행 초기화를 우선한다. 초기화는 확인 단계를 둔다.
화면은 작품 표지를 중심으로 한 밤바다 포스터와 종이 편지의 대비를 사용하며, 동일한 둥근
카드가 반복되는 범용 앱 구성을 피한다. 세부 기준은 [시각 방향](visual-direction.md)에서 관리한다.
자유 입력, 자유 이동 지도, 방 꾸미기, 소셜, 클라우드 동기화는 후속 후보다.
첫 배포는 한국어이며 다국어 출시는 별도 범위로 결정한다.

## 다음 작품 후보

마지막 열차(추리), 심야 상담소(관계), 궤도 밖 신호(생존), 마녀의 잡화점(선택의 후일담).
현재 제작 승인이 아닌 후보 목록이다. 첫 작품 평가 후 두 번째 작품을 고른다.

## 단계별 산출물

1. 준비: 디렉터리, 기술 설계, 콘텐츠 계약 초안 — 완료.
   초기 기반 설계: [ERD·저장 계약](data-design.md), [구현 순서](foundation-plan.md) 작성.
2. 작은 플레이 시제품: 기술 fixture와 「내일의 소인」 9노드/2엔딩 개발 원고 구현.
   분기·저장·이어하기, 양 플랫폼 전체 UI 경로와 네이티브 저장 검증 완료. 소수 플레이테스트는 미실행.
3. 첫 작품 완결: 18노드·2엔딩 확장 원고 v3 구현 — 진행 중. 플레이테스트·퇴고·아트/사운드·실기기 검증 필요.
4. 비공개 테스트: 읽기 편의·선택 영향·완주 경험 점검 — 미착수.
5. 출시 준비: 스토어 계정·서명·등급·개인정보 안내·스크린샷 — 미착수.

## 필요한 제작 자원과 남은 결정

원고와 분기 설계, 인물 설정, 편지 UI, 배경/초상/아이콘, 폰트, BGM/효과음,
실기기 테스트, 스토어 소개 자료가 필요하다. 임시 에셋으로 먼저 재미를 확인한다.
에셋은 직접 제작 또는 권리가 확인된 자료를 사용하고 출처를 남긴다.
브랜드명, 우선 테스트 기기, 아트 스타일, 출시 국가, 유료화 시점은 미확정.
과금은 첫 에피소드 무료+작품 구매 후보이며 초기 시제품에는 넣지 않는다.

## 현재 검수 범위 — 2026-10-01

v4 draft에서 소품·시간·합류 장면의 연속성과 두 엔딩의 행동을 보강했다. [확장 원고 검토](little-post-office-expanded-draft.md)가 서사 검수의 기준이며, 감정의 설득력과 실제 독서 시간은 플레이테스트로 평가한다. AI 제작은 제안·검토·적용·저장을 분리하고 미완성 연출 계획을 원장에 보존한다. v4의 앱 등록, 사운드 제작·재생과 실제 API 품질 평가는 아직 완료하지 않았다.

## 제작 도구 보강 — 2026-10-02

새 편지·결말을 기존 장면의 선택지에서 연결하는 폼, 한국어 필드/참조 목록, 미저장 원고의 엔진
플레이 미리보기와 백업·검증 복원을 구현했다. 원장의 서버 revision과 편집 세션을 분리해 다른
탭의 덮어쓰기 및 늦은 응답으로 인한 변경 손실을 차단한다. 원격 게시나 협업 CMS는 추가하지 않았다.
장면 제목·본문 검색과 참조 관계를 검사하는 삭제·직전 구조 변경의 1단계 취소도 구현했다. 검수 시점의 원장 스냅샷·식별값·시각·제작표·분기 JSON 내보내기를 구현하고 공유 모듈·HTTP·브라우저 검증을 통과했다. v4 바닷길 이미지는 내장 ImageGen으로 생성해 연출 원장에 연결했다. 사운드 제작·네이티브 v4 등록·사람의 플레이테스트는 별도 검증이 필요하다.


선택지 조건·효과 폼을 구현하고 자동·모바일·키보드 검증을 통과했다. boolean 상태의 노출 조건과 선택 후 변화를
한국어 상태 목록으로 편집하며 전체 분기 검사 후 적용한다. 새 상태 정의와 새 작품 생성은
고급 원장/후속 도구 범위로 남긴다.
