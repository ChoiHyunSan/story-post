# 시각 방향

2026-09-25 기준. 범용 카드 UI를 걷어내고 작품의 소재가 화면 구조를 결정하도록 정리했다.

## 방향

「작은 세계 우체국」의 핵심 이미지는 비 오는 섬의 밤, 썰물 길, 마지막 우편함과 오래된
편지다. 작품 목록은 세로 포스터 한 장처럼 보이고, 읽기 화면은 어두운 바다 위에 놓인 실제
편지처럼 보여야 한다. 장식은 표지와 소인에 집중하고 나머지는 조용하게 둔다.

피해야 할 기본값은 동일한 둥근 카드 반복, 영문 대문자 브랜드 라벨, 장식용 그라데이션,
모든 정보를 가운데 정렬한 버튼 묶음, 의미 없는 그림자다. 상태·설정·오류는 작품의 분위기를
유지하되 기능 이름과 복구 행동을 분명하게 쓴다.

## 토큰

| 역할 | 값 | 사용 |
| --- | --- | --- |
| 밤바다 | `#07161F` | 앱 배경 |
| 젖은 청록 | `#102832` | 설정·기록 패널 |
| 묵은 종이 | `#F2EBDD` | 편지 본문 |
| 창문 불빛 | `#E7BC72` | 주요 행동·진행 강조 |
| 잉크 | `#263238` | 편지 본문 |
| 안개 | `#9BAEAD` | 보조 정보 |

제목과 편지 본문은 iOS `New York`, Android `serif`를 우선하고 조작과 상태 정보는 시스템
산세리프를 사용한다. 본문은 한 줄을 짧게 유지하고 글자 확대 시 자연스럽게 세로로 흐르게 한다.

## 화면 계약

- 목록: 작품 표지, 제목, 소개, 예상 시간, 수집 결말, 진행 상태와 한 개의 주요 행동을 한
  포스터 안에 둔다.
- 읽기: 발신인과 소인, 본문, 선택지를 한 장의 종이 안에 둔다. 선택지는 채운 버튼 대신
  문장형 행으로 보여 본문 흐름을 끊지 않는다.
- 기록·설정: 밤바다 패널을 사용하며 편지 본문과 시각적으로 구분한다.
- 접근성: 최소 48pt 조작 영역, 색 외의 텍스트 상태, 큰 글자, 화면 움직임 줄이기와 기존
  스크린리더 이름을 유지한다.

iOS 1170×2532와 Android 320dp·시스템 글자 130%에서 목록을 확인했다. iOS에서는 편지 본문,
화면 밖 선택지의 접근성 이름과 실제 선택 후 다음 장면 전환까지 확인했다.

## 표지 에셋

`assets/little-post-office-cover.jpg`는 프로젝트 전용으로 OpenAI 내장 ImageGen을 사용해
생성했다. 외부 참조 이미지는 사용하지 않았다. 생성 원본 PNG를 품질 82 JPEG로 변환해
2.8MB에서 약 536KB로 줄였다. 개발 빌드에만 포함하고 프로덕션 export에서는 hash 검증으로
제외한다. 원본 프롬프트는 [에셋 기록](../assets/README.md)에 보관한다.

## 제작실 플레이 미리보기

기존 밤바다·편지 게임의 토큰을 유지한다. 배경은 night #0b0e11와 panel #11161a, 본문은 paper
#ddd4c2 / ink #25231f, 보조 문구는 muted #979b9e, 포커스는 #f4b36c를 사용한다.
탐색은 시스템 sans, 원고는 모바일의 편지 읽기와 같은 serif 계열과 넓은 줄 간격을 사용한다.
최대 720px의 한 열 편지를 왼쪽 정렬하고 선택지는 종이 아래 연속된 문장으로 이어진다.
새로운 대시보드 카드나 장식적인 상태 라벨보다 원고와 실제 선택을 우선한다.

제작실 모바일 헤더는 브랜드/작업 상태의 두 행으로 배치해 미저장·실패·완료와 저장 버튼을
본문 스크롤 중에도 유지한다. 편지와 생성 장면 제목의 scroll margin은 헤더 높이보다 크게 두어
키보드 포커스 이동 후 읽기 시작점을 가리지 않는다. 제작 폼은 ID보다 한국어 장면 제목을 먼저
표시하고, 고급 테이블에서만 CSV의 내부 열 식별자를 그대로 사용한다.
